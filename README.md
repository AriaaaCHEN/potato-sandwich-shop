# 🥔 吉伊卡哇土豆泥鸡腿三明治店

> 一款基于 Qt 5.9.2 开发的桌面休闲模拟游戏  
> 南开大学 C++ 大作业项目

---

## 📖 项目简介

在可爱的吉伊卡哇世界里，你是一名三明治厨师。  
根据顾客订单，使用 **土豆、黄油、牛奶、面包、生菜、鸡腿排** 等食材，  
制作出完美的 **土豆泥鸡腿三明治**！

游戏包含 **连击奖励、最高分记录、难度选择、星级评价** 等机制。

---

## 🎮 游戏玩法

1. 点击食材加入碗中  
2. 同时拥有 **土豆 + 黄油** 时，点击 **搅拌** 可获得 **土豆泥**  
3. 按照订单要求组合食材，点击 **提交** 完成订单  
4. 做错可点击 **丢弃** 清空碗，重新尝试  
5. 倒计时结束根据完成订单数评定星级 ⭐

---

## ⚙️ 难度模式

| 难度 | 倒计时 | 订单复杂度 |
|------|--------|------------|
| 简单 | 60 秒 | 土豆泥 + 面包 |
| 普通 | 60 秒 | 基底 + 1 种随机食材 |
| 困难 | 60 秒 | 基底 + 2 种随机食材 |

---

## 🏆 特色系统

- 🔥 **连击奖励**：连续成功 3 次额外 +5 分，5 次额外 +10 分  
- 🏅 **最高分记录**：最高分自动保存，下次启动依然存在  
- 😊 **表情反馈**：订单成功/失败时有可爱的表情提示  
- ⭐ **星级评价**：游戏结束后根据完成订单数评定 1~3 星  

---

## 🖼️ 游戏界面

- 厨房俯视视角，马赛克可爱风格
